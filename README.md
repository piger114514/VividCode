# vividcode

**把源码中的文件、类、函数和引用关系画出来，帮助你更快理解一个项目。**

vividcode 是一款面向 Windows 的代码分析与可视化工具，支持 C/C++、C#、Python、JavaScript/TypeScript 和 Java。你可以从项目全貌逐步展开到具体符号，沿着关系查看源码，也可以配置 AI 生成文件讲解，或连接本机 Pi Coding Agent 辅助修改代码。

[下载安装包](https://github.com/piger114514/VividCode/releases) · [反馈问题](https://github.com/piger114514/VividCode/issues)

首个面向用户的发布版本：**0.1.0**（Windows x64）。

## 可以用它做什么？

- **了解陌生项目**：浏览文件、类、函数和变量，查看调用、继承、实现、覆写与引用关系。
- **追踪代码关联**：展开文件或类，聚焦某个符号，查看关联文件，并定位关系发生的源码位置。
- **阅读多语言工程**：不同语言的分析结果显示在同一画布中，文件颜色和关系颜色帮助区分内容。
- **获取 AI 讲解**：接入 OpenAI 兼容接口，为源码生成初学者、进阶或专业程度的解释。
- **使用 Pi 辅助开发**：在项目内与本机 Pi 对话，恢复历史会话，并按需在任务结束后更新关系图和 AI 解释。

界面支持简体中文和 English。在顶部“语言 / Language”中切换后，重新打开程序生效。

## 下载与安装

目前提供 **Windows x64** 版本。

1. 打开 [Releases 页面](https://github.com/piger114514/VividCode/releases)，选择需要的版本。
2. 展开该版本的 **Assets**，下载 `vividcode-Setup-<版本号>-x64.exe`。`Source code (zip)` 和 `Source code (tar.gz)` 是源码压缩包。
3. 运行安装程序并选择安装目录。首版安装包包含全部五种语言分析组件。
4. 安装完成后，重新打开 PowerShell 或终端，使 `vividcode` 命令生效。

升级前请关闭正在运行的 vividcode，运行新版安装程序并选择原安装目录。各项目的启动入口共用已安装的程序，更新后重新打开即可使用新版。

### 按使用的语言准备环境

安装包提供所选语言的分析组件。分析源码还需要相应的本机开发环境，只需准备你实际使用的语言。

| 项目语言 | 分析所需环境与配置 |
| --- | --- |
| C/C++ | Python 3.12+ x64、LLVM/libclang，以及项目的 `compile_commands.json`、头文件和依赖 |
| C# / Unity | 项目所需的 .NET SDK、工作负载和引用，以及 `.sln` 或 `.csproj`；Unity 项目需要先在编辑器中生成工程 |
| Python | Python 3.12+ x64，包含 `sqlite3` |
| JavaScript / TypeScript | Node.js 22 或 24 x64；支持 JSX/TSX 和 `tsconfig.json` / `jsconfig.json` |
| Java | 完整 JDK 17+；按项目需要配置源码根和依赖路径 |

程序找不到开发工具时，可以在关系图中右键打开“分析环境…”，填写本机工具路径。某种语言缺少环境不会阻止其他已配置语言的分析。普通源码浏览不要求安装全部语言环境。

## 快速上手

在你要查看的项目根目录打开 PowerShell，运行：

```powershell
cd "D:\Projects\MyProject"
vividcode -g
```

完成后，双击项目内的 **`.vividcode\vividcode-viewer.exe`** 打开查看器，也可以在 PowerShell 中运行：

```powershell
.\.vividcode\vividcode-viewer.exe
```

程序会读取项目配置并开始分析。首次分析可能需要一些时间；之后打开项目会先显示已有结果，再检查变化。C/C++ 项目如果没有自动找到 `compile_commands.json`，可在画布右键导入工程配置。

`.vividcode` 保存项目入口和生成记录，可以将它加入项目的 `.gitignore`。生成记录不是源码备份。

## 浏览关系图

| 操作 | 用途 |
| --- | --- |
| 左侧文件树与“结构与关系” | 浏览文件、类、函数和变量，按路径筛选文件 |
| 单击节点或连线 | 突出相关节点与连线 |
| 双击缩略节点 | 展开文件或类的详细内容 |
| 双击左侧结构中的符号 | 查看该符号关联的文件 |
| 右键节点或连线 | 查看定义、选择引用发生处并打开只读源码 |
| 滚轮、拖动节点、在空白处拖动 | 缩放、调整节点位置、平移画布 |
| 关系类型和范围筛选 | 减少画布内容，集中查看关注的关系 |
| `F5` 或右键刷新 | 修改源码后更新分析结果 |

**箭头从“被引用者”指向“引用者”。** 例如 A 调用 B，图中显示为 **B → A**，方便查看哪些代码依赖某个符号。

连线通过颜色和线型区分关系，不在线上叠加文字；可通过图例或悬停提示查看含义。虚线表示可能的调用目标。节点较多时，可以右键“全部简化”，再展开需要查看的部分。

C# 项目的 **Debug / Release** 用于选择分析配置。“目标框架”通常留空即可；多目标框架工程需要指定某个目标时，填写工程中的框架名称，例如 `net8.0`。

## AI 文件讲解（可选）

1. 打开“AI 设置…”，填写 OpenAI 兼容服务的 Base URL、模型名称和 API Key。
2. 选择讲解语言，以及“初学者 / 进阶 / 专业”程度。
3. 点击“AI 解析”，等待讲解生成。
4. 单击画布中的文件或符号，查看所在文件的讲解；点击空白处收起。

已生成的讲解会缓存，后续根据源码变化和依赖影响更新。单击节点查看已有讲解不会发起新的 AI 请求。

**启用 AI 解析会将相关源码发送到你配置的服务，可能产生 API 费用。** API Key 使用 Windows 用户加密保存。不配置 AI，也可以使用文件浏览和代码关系分析。

## Pi 对话（可选）

先在本机安装并配置 Pi Coding Agent 的模型与登录信息，再打开 vividcode 中的 **pi** 页签。程序会尝试连接本机 Pi；如果未找到，可在“Pi 设置…”中指定 Pi 和 Node 的路径。

- `Enter` 发送，`Shift + Enter` 换行；任务进行中可以追加要求。
- 历史列表只显示当前项目的会话，标题取用户第一条消息的开头，过长时截断。
- 可以新建会话或切换到已有会话继续交流。
- “每次任务结束后更新代码关系和 AI 解释”默认关闭，可按需开启。

Pi 使用自己的模型和凭据，与“AI 文件讲解”的接口配置独立。**Pi 可以修改项目文件并执行命令；点击“停止”不会撤销已经写入的修改。** 建议使用 Git 保存需要保留的版本。

## 常用命令

在目标项目根目录执行：

| 命令 | 用途 |
| --- | --- |
| `vividcode -g` | 生成或刷新项目记录和启动入口 |
| `vividcode -sg` | 强制扫描，解除普通模式的数量和单文件大小限制；大型工程可能占用较多资源 |
| `vividcode -c` | 设置所有项目共用的源码文件数量上限 |
| `vividcode -n` | 清理旧记录，只保留最新成功记录 |
| `vividcode -d` | 删除当前项目的生成数据和集中缓存；请先关闭查看器，不会删除项目源码 |
| `vividcode -help` | 查看命令帮助 |

生成过程中，在当前终端输入 `stop` 并回车可以取消。默认源码文件数量上限为 20,000；强制模式仍会排除 `build`、`node_modules` 等目录以及链接路径。

## 常见问题

**安装后提示找不到 `vividcode`？**

先关闭并重新打开终端。如果从 IDE 内置终端运行，也需要重新启动 IDE，让它读取安装后的环境变量。

**打开项目后没有关系图？**

查看分析状态和诊断信息，确认安装了对应语言组件、本机开发环境可用、工程配置和依赖完整。C/C++ 需要真实的编译数据库；Unity 需要先生成最新工程；Java 的依赖需要按项目配置，目前不自动导入 Maven/Gradle 工程。

**为什么某些调用或引用没有显示？**

关系图来自静态分析。反射、运行时动态调用、缺失依赖等情况可能无法准确解析；较大的结果也会受到画布显示上限影响。图用于帮助理解代码，不能替代编译器、调试器或运行时分析。

**保存源码后会自动更新吗？**

目前不持续监视文件变化。修改后使用 `F5` 刷新；Pi 任务可以单独开启结束后自动更新。

**当前有哪些限制？**

目前不支持跨语言调用关系、关系图布局持久化和 Maven/Gradle 自动导入。源码查看器为只读，Pi 对话则可以通过本机代理修改文件。大工程建议配合范围筛选和符号聚焦使用。

## 从源码构建

普通用户直接下载安装包即可。自行构建需要 Windows x64、Visual Studio 2022 C++ 工具链、Qt 6.11.2 MSVC 64 位和 CMake。

下面以启用 JavaScript/TypeScript 分析为例，在仓库根目录运行：

```powershell
cd VividCode
.\build.ps1 -Languages @('javascript') -DownloadDependencies
.\install-command.ps1 -Languages @('javascript')
```

`-Languages` 可选 `cpp`、`csharp`、`python`、`javascript`、`java`。它表示本次安装的完整组件列表，升级时请包含所有需要保留的语言组件。`-DownloadDependencies` 允许准备分析库依赖；语言运行环境仍需自行安装。构建脚本支持通过 `-QtRoot` 和 `-CMake` 指定工具路径。
