# vividcode C# analyzer dependencies

Uses Microsoft .NET Compiler Platform (Roslyn) 4.14.0 and Microsoft.Build.Locator
1.7.8, distributed under their MIT licenses. Transitive packages and integrity
hashes are recorded in packages.lock.json. The .NET runtime and SDK used by the
analyzed project are provided by the user's .NET installation.
