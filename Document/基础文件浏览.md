## 源码职责与关键入口

源码均在 `../VividCode/`。主窗口类为 `VividCodeWindow`，Qt UI 类型为 `Ui::VividCodeWindow`，由 `VividCode.ui` 自动生成 `ui_VividCode.h`。

`openProject` 通知 SemanticPanel 读取缓存及后台更新，`sourceRequested` 信号定位项目内源码；关系定位可以加载扫描列表外的项目内文件。关系图、地图式类/成员层级及验证见 [C++ 语义索引](C++语义索引.md)。文件卡片及其选择信号已移除，文件树继续保留全部扫描结果。

| 文件 / 入口 | 职责 |
| --- | --- |
| `main.cpp` | 创建 QApplication 与主窗口；支持唯一项目路径参数，接收启动器 --project 参数，兼容旧部署上级项目定位并持有运行锁；`--self-test` 进入冒烟测试 |
| `VividCode.h` | 声明主窗口控件、根路径、当前文件和文件列表状态 |
| `VividCode.cpp` 构造函数 | 建立界面与信号连接；主窗口快捷键、文件筛选、树选择及源码定位 |
| `VividCodeWindow::openProject` | 检查目录、扫描与更新记录；关闭源码弹窗，记住仍存在的文件选择，自动调度各语言分析 |
| `scanProject`，位于 `ProjectScanner.h` | 迭代遍历目录并返回相对文件路径、排除目录数、是否达到上限 |
| `VividCodeWindow::rebuildViews` | 根据文件筛选重建目录树；重建期间阻断控件信号 |
| `SemanticPanel.cpp`、`RelationGraph.cpp` | 语言分组调度、统一结果、配置/范围/关系类型与结构树、分区图及右键菜单 |
| `VividCodeWindow::showFile`、`SourcePopup.h` | 限定项目内路径与大小，UTF-8 读取，菜单关闭后显示只读工具窗口 |
| `VividCode.ui` | 原始 Qt 主窗口外壳；主要布局在 C++ 中创建 |
| `SmokeTest.h` | 临时目录中的行为检查与项目窗口离屏渲染 |

主要流程：打开项目 → `openProject` → 扫描及各语言分析 → 文件树/结构树/分区画布 → 右键查看源代码 → `showFile` → SourcePopup。

## 扫描规则

- 支持扩展名：`c/cc/cpp/cxx/h/hh/hpp/hxx/inl/ipp/cs/py/pyw/pyi/js/jsx/mjs/cjs/ts/tsx/java`，不区分大小写。
- 不跟随符号链接。
- 排除目录名：`.git`、`.vs`、`.codegraph`、`.codemap`、`.vividcode`、`build`、`out`、`x64`、`x86`、`debug`、`release`、`node_modules`、`vendor`、`third_party`、`_deps`、`CMakeFiles`，以及 C#/Python 的 `bin`、`obj`、`__pycache__`、`.venv`、`venv`、`env`、`.pytest_cache`、`.mypy_cache`、`.tox`、`.idea`，JS/TS 的 `dist`、`.next`、`.nuxt`、`.cache`、`.parcel-cache`、`coverage`，Java 的 `target`、`.gradle`、`.mvn`，还有 `build-*`、`cmake-build-*`。`.codegraph` 属于开发辅助工具；`.vividcode` 属于本产品生成目录。
- 最多收集 5,000 个源码文件或访问 50,000 个目录条目，达到上限会显示提示。
- 扫描在主线程执行；大型目录可能暂时阻塞 UI。无权限的子目录可能无法列出，尚无逐目录错误汇总。

## 交互与边界

- 默认使用黑色/深灰背景与浅色文字，工具栏、页签、文件树、源码区及语义页采用统一配色。`main.cpp` 在创建窗口前设置 Fusion 控件样式、`QPalette` 和应用级 `setStyleSheet`；避免系统深色主题的白字与旧白色背景混用。当前没有主题切换按钮。
- 修改界面颜色时先看 `main.cpp` 的配色；`VividCode.cpp` 构造函数控制主布局，`RelationGraph.cpp` 控制节点、类容器、连线和画布。图元需要独立设置画刷，不能只改 QWidget 的样式表。主背景为 `#101010`，控件背景为 `#181818`，正文为 `#f0f0f0`。
- Ctrl+O：选择目录；F5：重新扫描当前目录。刷新清空筛选，并尝试保留当前文件。
- 项目切换或刷新关闭并清空源码弹窗。当前项目目录失效时，刷新入口清空文件视图并提示。
- 筛选为不区分大小写的相对路径子串匹配。
- 文件树保留全部已扫描的匹配文件，不再创建文件卡片。C++ 关系图有单独的节点/连线显示上限、符号选择和关系类型筛选；文件名筛选只影响左侧树，不改变编译数据库的索引范围。
- 关系图支持滚轮缩放、平移、节点拖动、类内符号按缩放展开及源码定位；顶部缩放和适应画布按钮已移除，布局尚未持久化。
- 源码小窗口仅显示只读代码和关闭按钮，定位到索引行/列；按 UTF-8 解码，超过 2 MiB 不加载；GBK 等编码不自动识别。路径和行号证据保留在关系图/列表及右键菜单。
- 已有文件级历史记录和独立 C++ / C# 语义缓存，但没有后台自动文件监控、最近项目恢复、代码编辑、语法高亮或行号栏。
