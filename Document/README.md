## 维护要求

- 按功能组织，优先更新现有同类文档，避免为每次修改新建一份重复日志。
- 写清当前行为、源码文件、关键入口、运行方法、实际验证、已知限制和未完成事项。
- 环境检查失败需记录具体原因；访问拒绝不等于文件不存在。
- 不把未运行的测试、未实现的规划写成已完成。
- JavaScript/TypeScript、Java、C#、Python 当前仅支持文件浏览；C++ 已接入真实 libclang 分析。历史阶段记录不替代最新实现与验证说明。
- 用户特别要求的初学者解析采用 `.txt` 格式，后续相关代码变化应同步更新 `vividcode代码解析.txt`；其余功能文档继续优先更新已有同类文件。
