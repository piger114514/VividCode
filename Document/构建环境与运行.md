## 在原始 Visual Studio 解决方案中找到 CLI

1. 重新打开 `CUGB_Graph.sln`，或接受 VS 的“重新加载”提示。
2. 展开 `vividcode → Source Files → cli_main.cpp`；同组还有 ProjectStore.cpp，头文件在 Header Files 下。
3. 使用 **Release / x64**，生成整个解决方案。CLI 项目引用查看器项目以保证构建顺序，但不把两个 main() 链接到同一个程序。
4. 原始 VS 产物在 `CUGB_Graph/x64/Release/`，CMake 产物仍在 `CUGB_Graph/build/Release/`。两套构建使用同一份源文件，各有输出目录。
5. 需要调试控制台时，将 vividcode 设为启动项目；默认命令参数为 --help。需要调试窗口时，选择 vividcode-viewer。

Release 构建的 CLI 项目会部署 Qt 运行依赖、离屏测试插件和 demo 到同一输出目录。运行 --g/--c/--d 时，工作目录必须是想处理的目标项目目录。

已有 PATH 注册仍指向 CMake 的 build/Release。验证原始 VS 的新产物时请使用 x64/Release 中的 exe 完整路径，避免把旧的 CMake 产物当成本次编译结果。
